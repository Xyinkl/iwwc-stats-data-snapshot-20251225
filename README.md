# IWWC 数据分析工具集

本仓库拟提供一套工具来分析 IWWC (Ingress World Wide Competition) 的数据快照，用于检测和分析玩家数据的异常变化。

## 📦 重要须知


>自从我的文章《观IWWC竞赛榜有感——当世界级肝帝遇上小学数学》
>（https://vtx.space/archives/IngressWorldwideScamCompetition）
>被不知道哪位转到IWWC官方群后，经历了
>“群老中秒变外宾齐贺圣诞节事件”
>“群管理气势汹汹给Warning事件”
>“两小时数据榜单丝滑下架事件”
>“中非夜谈十动然拒尴尬收尾事件”
>不得不说，十分精彩。


>为了回应IWWC管理员关于————“提出真正有见解的数据分析，而不是用AI简单摆弄数字”的回应。
>我放下静态的榜单数据，开始认真研究IWWC的过往比赛数据。
>本仓库从eigood.github.com fork得来，原仓库目前仍然开放，也可以fork原仓库。
>感谢组织方使用Github这么开放的平台存储比赛数据，要没这个，怕又是一桩悬案。
>操作的数据都是Fork得来，从commit历史中可以看到我并没有对数据做任何修改。

>以下为没有认真看过IWWC数据的新人简单介绍一下我个人现在的观察结论：

>iwwc-info记录了比赛的周期，以及一些相关变量。（不是很重要）
>重要的是以下两类，这两类可以互相佐证。
>iwwc-custom开头的记录了变化量，也即比赛开始点视作数据零点，随着参赛选手逐渐上传数据，这个json文件会每隔一个小时更新一次。所以你会看到commit都是以小时为单位，自动提交的。
>iwwc-now则记录了数据绝对值，相对来说更能反应数据提交时点的玩家数据。
>后面的数字很明显标志了IWWC比赛的年份。

>IWWC比赛以一个月为竞赛周期，而玩家上传数据每周一次。
>所以完赛的人在一个比赛周期，大概率会有5次数据上传，日期也相对固定（某个月的1日/8日/15日/22日/下月1日）

>对于每个commit切片，json文件中的内容，都是一份当时的所有人数据集。
>如果要比对数据，也只需要使用git 反复切换不同commit即可。

>因此代码就是很简单的，不断切换commit，读取出数据来，再加减乘除（当然主要是减）
>本仓库比原仓库多的内容是最新添加的两个Python脚本，分别是puncheur_check.py 和 compare_commits.py
>作用分别是一键查看Puncheur君的卓越数据和细致比对某个提交节点的详细数据。

>代码绝大部分都是AI写的，备注齐备。具备半个月的编程经验就可以轻松读懂、修改。
>好了，说了这么多，如果你手头有电脑，那你也可以开始分析了。
>代码也不难，随便改改就能跑。

## 🚀 快速开始

### 1. 一键查看 Puncheur 数据异常

```bash
python3 puncheur_check.py
```
或者用这个，anyway看你怎么装的python了。
```bash
python puncheur_check.py
```

这将显示 Puncheur 玩家在 5 个关键 commit 的横向对比，包括：
- 2025-09-01: 首次记录
- 2025-09-08: 正常游戏期
- 2025-09-15: 正常游戏期
- 2025-09-22: **异常开始** (drone_sender 0→675)
- 2025-10-01: **持续异常** (drone_sender 675→981)

### 2. 详细比较两个 Commit，可修改玩家ID

```bash
# 比较 2025-09-22 的异常变化
python3 compare_commits.py d77cf892^ d77cf892 Puncheur

# 比较 2025-10-01 的异常变化
python3 compare_commits.py 3a143ab6^ 3a143ab6 Puncheur
```
